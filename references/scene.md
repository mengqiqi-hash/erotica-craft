# L2 场景构建

性场景是情色文学的承重墙。分析场景 = 拆三幕结构 + 量节奏 + 看视角。

## 三幕结构

### 第一幕：进入（铺垫）

功能：制造"即将发生"的张力。长度因流派而异——雅文可以铺垫数章，快餐文三句话内完成。

进入方式清单：
- **空间营造**：封闭空间（密室/房间/浴室）、公开空间（城楼/会场/地铁）——空间本身是张力来源。公开空间的"被看见风险"是免费的悬念。
- **借口装置**：治病（"这是最新的治病方法"）、练功（"需要阴阳调和"）、游戏（脱衣麻将/国王游戏）、交易（潜规则/契约）——给角色一个"不得不"的台阶，保住人物最后的尊严，这个尊严正是后面要撕掉的。
- **权力铺垫**：强者威胁/弱者哀求/身份压制——在进入前把权力关系摆上桌。
- **感官先导**：先写呼吸、心跳、视线、衣料摩擦声，再碰身体。视觉→触觉→听觉的递进比直接上手有层次得多。

```text
「林玄言望着季婵溪曼妙灵秀的腰背曲线，那衣领微微向下，露出了脖颈下一片雪白的肌肤。他很不争气地咽了口口水。」
```
（进入前：视线先于身体，吞咽先于触碰）

### 第二幕：推进（主体）

动作 + 感官 + 对话三轨交替，避免单一轨道疲劳。

- **动作轨**：身体行为的变化（脱衣→抚摸→进入→变速）。动作要具体可感，动词要准确（"抽插""研磨""顶弄"承担不同的节奏暗示）。
- **感官轨**：触觉（紧致/湿润/温度）、听觉（呻吟/撞击声/喘息）、嗅觉、视觉（身体的反应）。感官密度是场景"浓度"的指标。
- **对话轨**：情话/淫语/求饶/命令。对话推进比叙述推进更有戏剧性——人物在性事中说的话，暴露的是关系。

推进中的节奏变化：
- **变速技巧**：快-慢-快。突然的停顿（"他忽然停住"）比持续的高速更有力——停顿制造"她会不会求我"的悬念。
- **打断技巧**：中途插入外部事件（有人敲门/电话响/有人进来），制造中断与重新进入的双重快感。
- **时间线并置（交叉剪辑）**：把"风险"写成一个正在移动的人——偷情正酣时，丈夫/外人以日常行为（买菜、下班、取东西）同步逼近现场。两个画面交替呈现，恐惧与快感同步升级。这是人妻偷情流派的招牌手法（见 genres.md 流派六），任何需要"紧迫感"的场景都可借用。写法要点：丈夫线的日常动作必须具体（买什么菜、走到哪个路口），逼近的距离就是倒计时；妻子线的性动作与之交替剪辑，距离越近，剪辑越频繁。示例见 samples.md 悬置类条目。
- **重复与变奏**：同一动作的重复（"又一记巴掌落下"）配合变化（力度/位置/对象）形成节奏型。

```text
「他手指拨开了那两片花瓣……随后阳具猛然插入，毫不拖泥带水。那势大力沉一击直接贯穿而下。」
（老派/雅文的插入：要么极端暴力直入，要么极端温柔试探——两个极端都比温吞有效）

「玲玲立刻痛的大叫：好痛！呜……好痛喔！……任何男人都不会笨到拔出来吧」
（快餐文的推进：生理反应 + 角色吐槽式内心独白并行，粗粝但高效）
```

### 第三幕：收束（高潮与余韵）

高手与庸手的真正分野。庸手在高潮后戛然而止或流水账；高手在余韵里埋三个东西：

1. **心理落差**：高潮后的清醒、羞耻、后悔、空虚——身体高潮 vs 心理落差的对比是心理深度的来源。
   ```text
   「黄蓉何等身份，自打出娘胎从没受过这种羞辱，加上刚才高潮已过，情欲慢慢褪去，理智重新恢复过来，瞬间怒气冲顶……一掌打在贾易胸口」
   ```
   （高潮后理智回归 → 杀意爆发 → 一掌打飞。身体与意志的拉锯在余韵中结算）

2. **关系变化**：事后两人的关系发生了位移——权力易手、秘密形成、心理依赖开始。余韵是关系推进的存档点。

3. **情节钩子**：余韵里埋下一条非性情节线（有人来了/发现了什么/下一个目标出现），把性场景缝合回主线。

**高级收束：破局**（游戏/规则类装置专用）

当场景由规则装置驱动（脱衣麻将、国王游戏、赌约、交易），收束还有一种更狠的写法——**让装置本身失效**：

```text
「这把不算。」他把牌一推。
「为什么？」
「因为我想要的东西，牌给不了。」
```

- 破局 = 推倒牌 / 说"不打了" / 规则被打破。场景结束在"游戏失去意义"的瞬间，而不是牌局结束的瞬间。
- 规则是脚手架，拆脚手架的那一下才是戏。游戏失效的瞬间，两个人之间只剩下赤裸的权力关系——这才是真正的顶点。
- 破局的方式就是人物的表态方式：霸道的推牌、温柔的"不打了"、沉默的起身，写法必须和人设咬合。

## 伪装与表演场景（节拍完整性检查）

当人物在性场景中处于伪装状态（装醉、装睡、假装无意识、假装抗拒、假装自愿、假装屈从），戏的骨架由**表演链**支撑，不是由动作序列支撑。表演链缺一节，整场戏的叙事逻辑就断。检查时必须逐节核对：

1. **状态建立**：伪装状态要在铺垫幕明确建立（她喝了多少、他以为她什么状态），读者必须知道"她不是真醉/真睡"，但剧中人不知道。
2. **触发点**：伪装状态必然有一个被现实击穿的瞬间——何时"醒"、何时破功。触发点必须选在**戏剧最合理的时刻**，且要有生理或物理依据（被侵入的疼痛、身体被翻转、液体溅到脸上），没有依据的"醒"是穿帮。经典选择：完全进入后的瞬间，因为那时挣扎最合理、最痛、最像受害者。
3. **反应链**：破功后的反应必须逐级递进，不能跳级。典型链：惊醒（睁眼、确认这不是梦）→ 认知核对（身体上的重量/侵入感）→ 挣扎（推拒、扭动、蹬腿）→ 语言（慌乱质问"你干什么"，再升到身份意识"你不能这样"）→ 被压制（力气用尽、只剩肩膀抖）→ 哭泣。每一级都要有对应动作，跳级等于表演断裂。
4. **表演接管与维持**：从某个节点开始，人物的反应从"真实"转为"可控表演"（哭的节奏、挣扎的力度、台词的选择）。这个切换点要能被细读的读者从"行为"里辨认（挣扎力度"刚好"推不开、哭声"刚好"在他停顿时长起），但绝不写穿（禁止"她心想：哭到这里他该愧疚了"）。
5. **身体背叛的插入**：伪装者的身体反应（湿润、硬挺、收缩）与表演状态（抗拒、哭泣）的冲突是这类场景的心理内核，必须至少有一处实写（哭喊时下身湿了、推拒的手慢慢变成抓紧）。
6. **收场**：表演何时结束、怎么结束（收在具体物象上，如数到十、捡起房卡），以及事后人物"从表演里出来"的意识回归（凉意、心跳、环境音），都要有交代。

检查问题：把这场戏的表演链列出来（装→触发→醒→反应链→接管→收场），任何一节回答不出"具体动作是什么"，就是断裂，必须补。

## 视角调度

同一场景换视角，心理层次完全不同：

- **第一人称男主**：快感 + 占有感 + 控制感，天然代入。都市快餐文主视角。劣势：写不出女方的内心，除非靠观察。
- **女主内视角**：羞耻 + 矛盾 + 身体反应 vs 心理抵抗的拉锯。同人/凌辱文常用——因为这类文本的核心快感是"看她沦陷"，内视角让沦陷过程可感。
- **旁观者视角**：偷窥者/第三人的观察（"柳青萍冷眼旁观，暗里计算她尿了十多次"）。旁观者的评判（震惊/不屑/情动）为场景加一层滤镜，也提供了道德审视的锚点。
- **多视角切换**：雅文常用。同一场性事在 A、B、C 三人眼中分别呈现（身体视角/权力视角/羞耻视角），叠加出厚度。

## 节奏量化

分析时给场景做粗略节奏标注：

```
[铺垫 40%] [推进 45%] [收束 15%]   ← 雅文/凌辱文的经典配比
[铺垫 15%] [推进 70%] [收束 15%]   ← 快餐文的配比（进入极快，推进饱和）
```

判断标准：
- 铺垫 < 10%：纯器官交换，人物和关系是空白的 → 快感短期有效，读完即忘
- 收束 = 0：没有余韵，没有关系变化 → 场景是孤立的，无法推动叙事
- 最优原则：铺垫决定"值得不值得"，收束决定"记住了没有"，推进决定"爽不爽"。三者不可偏废。

**环境音节拍器**（节奏的具体抓手）：

借场景/游戏的天然流程做节拍器——洗牌嘈杂适合交锋，码牌安静适合凝视，出牌逐张累积悬念，胡牌爆发后是更深的安静。快慢交替靠落差，临界时环境音越写越细——人紧张时只听得见最细的声音（空调嗡鸣、衣料摩擦、远处车流）。写声音，其实是在写心跳。

## 写作指导要点

- 给每个性场景定三幕配比，再动笔。
- 进入前至少留一个"借口/台阶"（哪怕很薄），它决定角色的尊严起点。
- 推进中三轨（动作/感官/对话）轮流主导，每 100-200 字换一次轨。
- 收束必写三样里至少一样：心理落差 / 关系变化 / 情节钩子。规则类装置可用破局收束。

## 常见失误清单（写前自查）

1. **规则/装置太复杂**：读者不需要懂规则，只需要懂赌注。规则一句话讲完，装置细节服务于情绪，不服务于教程。
2. **每段都全力写**：局局高潮等于没有高潮。至少有一段要一笔带过，把力气省给关键段。
3. **升级顺序随意**：顺序就是剧本——从低价值物品到贴身层，每脱一件/每升一级，必须有一件被看见、被反应。
4. **对话太直白**：把欲望说破，双层结构（字面一层、潜台词一层）就塌了。保持"字面上在做别的事，潜台词在调情"。
5. **主角沦为被动**：双方都要有能动性，都在出招。一方只会害羞的戏是单人表演。
6. **忘了装置本身**：赌注再香，牌桌得是真的。读者要相信他们真的在打牌，才会相信他们真的在赌。
