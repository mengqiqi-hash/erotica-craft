# L5 类型惯例（流派技法）

每个流派有一个**核心装置**——读者真正为之而来的东西。先找出装置，再看它如何驱动情节与场景。

## 流派一：港台老派（章回体 + 淫术奇技）

**核心装置**：淫术/奇技系统——把性行为翻译成功法修炼，获得叙事"合理性"。

特征：
- 结构：章回体，回目对仗（"爱欲魔女""三霞计划"），常以"＊＊＊"分节
- 用词：半文半白，直球器官词 + 文言虚词并存
- 装置：淫欲真经、龙吐珠、铁甲桃花蛇、朱雀杵、采阳补阴、魔种
- 人物：淫邪教主/恶汉群像 + 名门侠女/圣女——身份落差是标准配置
- 招牌手法：**理性旁观者**（一个清醒角色在旁边计算、评判，反衬场景疯狂）
- 心理：受害者视角的"悲苦 + 身体诚实"（"更苦的却是心里的伤痛，因为一生幸福，已经让这群野兽毁去了"）

读者期待：**功法修炼的"合理性" + 名门正派被亵渎的落差 + 旁观者的评判视角**。

写作要点：奇技系统要自圆其说（每门功法有机制、有限制、有代价），它是这类文的"世界观税"，缴了才谈得上别的。

## 流派二：大陆修仙雅文（意象化 + 心理纵深）

**核心装置**：双修/采补——性与修炼合一，性事即升级，情欲与道心交战。

特征：
- 用词：古典雅词 + 意象替代系统（花瓣/珍珠/长剑/铁骑）
- 结构：长线叙事，性场景嵌在宗门/境界/恩怨主线里，铺垫极长
- 人物：清冷女仙/道心坚定的女主 + 强势男主/反派；"道心"是心理张力的核心词
- 心理：尊严/道心 vs 情欲/沉沦的拉锯（"出于尊严，她紧咬牙关，不让自己发出一丝呼痛的声音"）；公开羞辱（万人面前）与内心抵抗并置
- 身体：视线调度精致，环境光参与，比喻绑定山水剑器
- 招牌手法：**多视角叠加**（同一场景在男主/女主/旁观者眼中分别呈现）+ **暴力与唯美并置**（"血肉模糊"与"仙子凌尘"同框）

读者期待：**情欲的审美化 + 道心沦陷的过程性 + 修为与欲望的纠缠**。

写作要点：修仙文的性场景要与修炼体系挂钩（双修/采补/境界突破），心理层要写出"道心"的动摇过程——不是简单的羞耻，而是价值观层面的地震。

## 流派三：同人改写（原著关系 + 禁忌感）

**核心装置**：挪用原著人物关系制造禁忌（义子/师娘/掌门夫人/母女），原著性格的性化延伸。

特征：
- 用词：跟随原著风格（金庸同人则武侠腔，红楼同人则古典腔）
- 结构：在原著情节的缝隙里插入性场景（"原著+原创"双线并行）
- 人物：原著人物保留性格记忆（黄蓉的机敏、武功、身份），性场景让这些特质与情欲碰撞
- 心理：**关系标签即催情素**——"被自己的义子强行允吸乳头""对郭靖的愧疚感"——每一处原著关系标签都在加重禁忌感
- 招牌手法：**身份与身体的互搏**（"黄蓉何等身份……可是发情的女人"）——原著身份是心理张力的锚

读者期待：**熟悉的角色被陌生地对待 + 原著关系被亵渎 + 性格与情欲的化学反应**。

写作要点：同人改写的成败在于"像不像"——人物的性格、语言、关系必须忠实于原著记忆，性场景才有背叛感。先立人物，再写情欲。

## 流派四：都市快餐文（口语化 + 游戏化）

**核心装置**：日常场景/游戏装置被性化（脱衣麻将、国王游戏、宿舍、浴室），性事日常化。

特征：
- 用词：现代口语、极短句、重复句式、拟声词
- 结构：场景独立成章，进入极快（铺垫 <15%），对话驱动
- 人物：第一人称男主（"我"），女性角色类型化（清纯学姐/火辣学妹/成熟少妇）
- 身体：数字崇拜（36F/10寸）+ 食物比喻 + 白描
- 心理：羞耻阈值快速推进（"玲玲害羞的脱掉上衣" → 几段对话后"玲玲不要脸的说"），转变靠对话推动
- 招牌手法：**对话推进 + 游戏规则制造合理性**（输了脱衣服/国王游戏惩罚——规则替人物背锅）

读者期待：**高密度刺激 + 日常感 + 代入感**（"我"视角），不追求心理深度，追求效率。

写作要点：快餐文的节奏就是生命。对话要短、推进要快、每段要有进展（新动作/新反应/新台词）。游戏装置要规则清晰——规则是这类文的结构骨架。

## 流派五：凌辱调教文（权力落差 + 器械系统）

**核心装置**：身份落差 + 调教体系——把"社会身份的剥落"作为核心快感。

特征：
- 用词：道具词（电动阳具/电子潮吹器/丝袜束缚）+ 身份词（女警官/女教师/学生/奴隶）并置
- 结构：以"调教进程"为长线（从羞辱→器械→心理屈服），单场景为调教步骤
- 人物：施虐者（控制者）+ 受害者（身份高、处境低）；受害者心理是重点
- 身体：物化描写（容器/美肉/工具），服饰即身份符号（警服→丝袜→赤裸）
- 心理：**身份与欲望的撕裂**（"忘记了自己是人民警察""严肃的女警官屈服在淫威之下"）+ 羞耻-快感纠缠 + 深层麻木
- 招牌手法：**旁观者的复杂心情**（施暴者的兄弟/受辱者的亲人目睹时的心理）+ **器械的物理细节**（写实感）

读者期待：**身份的剥落过程 + 抵抗的无效性 + 心理防线的逐层瓦解**。

写作要点：凌辱文的深度在"心理防线的结构"——先立起角色的身份/尊严/理智（有多高），再一层层拆（就有多疼）。器械要写得物理上可信，否则失去真实感。注意：此类题材要确保成年角色。

## 流派六：都市人妻偷情（婚姻亵渎 + 绿文传统）

**核心装置**：婚姻关系被亵渎 + 丈夫的无知在场——快感来自"对婚姻誓言的背叛发生在丈夫眼皮底下"。代表作：《淫荡少妇白洁》（黄文界的《追忆似水流年》，都市绿文的泰山北斗）。

特征：
- 用词：写实白描，无流派性术语；衣物细节极具体（佐丹奴牛仔裤/深红紧身纯棉T恤/白丝袜），真实感是底色调
- 结构：**堕落弧线为全书骨架**（贞女→被迫→半推半就→习惯→主动），章节标题直接标注弧线位置（"贞女荡妇""风骚荡妇""淫荡贞女""欲海娇妻"），每章标题就是人物状态的进度条
- 人物：温婉妻子（保留"初心"——温婉气质与害羞本能是恒定锚点，不管睡了多少人都不变）+ 无知丈夫（被日常蒙蔽的对照物）+ 攻掠者群像（校长/局长/市长/流氓，从教育界到权贵界的阶梯式展开）
- 身体：白描 + 衣物细节 + 环境声（石英钟、水声、肉体撞击声），镜头感强
- 心理：**愧疚与快感的拉锯**（"身体已经对不起王申了，生活一定要对得起王申"）+ 堕落自我怀疑（"难道自己真是他们眼里的骚货吗"）
- 招牌手法：**时间线并置（交叉剪辑）**——偷情正酣时丈夫同步逼近（买西红柿的丈夫 vs 家里被插入的妻子），两个画面靠日常动作焊在一起，恐惧与快感同步升级

读者期待：**人妻身份的被亵渎过程 + 丈夫无知的讽刺 + 堕落弧线的完整性**（从抗拒到接受再到主动的每一步都要可感）。

写作要点：
- **堕落弧线要"每步都写"**：迷奸→要挟→半推半就→习惯→主动约会，不能跳步。每一步都是对上一部的背叛，弧线的完整度决定作品的厚度。
- **时间线并置是最强手法**：让丈夫/外人以日常行为（买菜、回家、取东西）逼近正在偷情的现场，把"风险"写成一个正在移动的人。
- **日常物件反讽**：丈夫手里的西红柿与妻子翘起的屁股并置，日常细节越无害，反讽越锋利。
- **初心保留**：人物无论堕落到哪一步，保留一个不变的锚点（温婉气质/害羞本能），反差张力才持续。
- **群像阶梯**：攻掠者按身份阶梯展开（校长→局长→市长），每上一个台阶，人妻的"被亵渎价值"升一级。

## 跨流派借鉴（进阶）

高手作品常跨流派取法：
- 修仙雅文 + 凌辱要素 → 高身份角色的公开羞辱（琼明的"万人面前打臀"）
- 同人 + 都市 → 现代同人（把原著人物搬到现代职场）
- 港台老派 + 武侠 → 传统"武侠色文"（功法 + 江湖 + 侠女）

分析混血文本时，先拆出它继承了哪些流派的装置，再判断组合是否自洽。
