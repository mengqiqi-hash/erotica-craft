# L4 心理刻画

情色文学的心理描写，核心张力只有一个：**"身体诚实" vs "意志抵抗"**。所有心理技法都是这一张力的变奏。

## 心理张力模型

```
意志层：尊严、身份、道德、理智、抵抗
   ↓  （拉锯）
身体层：快感、反应、渴望、沉沦
   ↓  （结果）
结算层：羞耻 / 屈服 / 清醒 / 报复 / 空虚
```

- **意志层**是角色"想维持的自我"：黄蓉是东邪之女、掌门夫人、郭靖之妻；白艳妮是人民警察；李菁霞是大学教师。
- **身体层**是"欲望的真相"：颤抖、湿润、呻吟、本能迎合。
- **结算层**是事件后的重新定位：羞耻、杀意、屈服、依赖、麻木。

分析心理 = 找出三层各自的"台词"，看作者如何让它们打架。

## 沦陷弧线（经典模型）

```
反抗 → 试探 → 半推半就 → 沦陷 → 事后羞耻/清醒
```

各阶段的笔法：

1. **反抗**：要写出"真反抗"与"象征性反抗"的区别。
   ```text
   「虽然手上仍象征性的做出反抗，但这种反抗在张大富眼中却更像是欲拒还迎的渴求」
   「其实就连黄蓉自己也明白这只是象征性的反抗」
   ```
   关键：**作者自己点破反抗的性质**（"连她自己也知道"），读者获得"她正在沦陷"的知情权——这是情色文学的核心快感来源之一：看着一个人一步一步输给身体。

2. **试探**：身体先于意志行动（"情不自禁的伸出了舌头""双手用力抱紧贾易的后脑"）——意志还没来得及反对，身体已经投了降。

3. **半推半就**：口头拒绝 + 身体迎合并置（"别……别……" + 肌肤发烫），语言与身体互相出卖。

4. **沦陷**：彻底放弃抵抗，主动求欢（"快，我快受不了了"）。沦陷瞬间要写"意志的最后一次闪光"——那一点残存的清醒让沦陷更有戏剧性。

5. **事后羞耻/清醒**：这是心理深度的试金石。
   ```text
   「加上刚才高潮已过，情欲慢慢褪去，理智重新恢复过来，瞬间怒气冲顶，眼间闪过杀意，聚起内力一掌打在贾易胸口」
   ```
   高潮 → 清醒 → 杀意 → 行动：完整的心理结算。越强的角色，结算越激烈。

## 观察者系统（心理层次的关键）

同一场性事，心理层次取决于"谁在看"：

- **伪第一视角（类型文学主视角）**：第三人称外壳 + 第一人称的感知内核。主语写"她/人物名"，但感知完全贴着主角走——口语感知动词（"觉着""感觉到"）直接上，自由间接引语（心声不加"她想"）直接用。它兼得第一人称的代入感和第三人称的灵活性：读者感到的是"我在场"，叙述却能随时切视角。
  ```text
  「她觉着自己快散架了，感觉着那一下一下的进出」
  「猛然，她感觉出下身真的有一条很硬的东西在插着，一下睁开了眼睛」
  ```
  注意：这两句感知贴着人物，但主语仍是"她"——这就是伪第一视角的形态。配合主语轮换（scale.md g项），同一文本内可切到对方视角。
- **第一人称（备用视角）**：真第一人称在类型文学中不常用——它锁死视角，不能切换到对方，写不了"她看不见的"。仅在特殊题材（日记体、书信体、回忆录框架）或有强理由时使用。
- **旁观视角**：主语=旁观者，她做宾语，用于偷窥/目击场景（《窗外》的"他看见她叫李局"）。
- **多视角叠加**：伪第一视角为主干，配合主语轮换切换人物，或用旁观视角做插叙——三层叠加出厚度。

**视角选择的默认值**：写性场景默认用伪第一视角（第三人称+紧贴感知+自由间接引语），除非有强理由才切换。模型默认倾向是"旁观视角"（她……她……她……，摄像头式），必须主动切到伪第一视角。

### 视角的语法实现（理论层 → 执行层）

观察者系统是理论（有哪几种视角），执行要靠句法（怎么让读者站进去）。**视角切换的引擎是主语选择**（scale.md 第13条 g 项）：每写一句，主语决定了读者此刻站在谁的身体里。

理论层的每种视角，在执行层的落地方式：

| 理论视角 | 执行句法 | 例 |
|---|---|---|
| 第一人称男主 | 主语=我，宾语=她 | 我扶着她的腰，往下按 |
| 女主内视角 | 主语=她（身体部位独立成句） | 腿间一下涌出热意 |
| 旁观者视角 | 主语=旁观者，她做宾语 | 他看见她仰着头叫"李局" |
| 双视角切换 | 主语轮流 = 视角轮流 | 他扒下她的裙子，她仰躺在床上 |
| 共享视角 | 身体部位做主语，两人同时在场 | 一对乳房在胸前隆起 |

**写实白描流的第三人称不是"单一旁观视角"，是主语驱动的双视角切换**：一个句子换一次主语，读者在两个人的身体里来回进出——站在男方的手上感受动作，跳进女方的身体感受被动作，再用"乳房"这种共享主语让两个人同时在场。作者从头到尾不说"他在看她"，读者却自动完成了这个观看。

**使用边界（head-hopping 提示）**：这种主语驱动的双视角切换是**类型文学**（白描流/色文）的既定技法，不等于正统叙事理论中的"视角切换"。在严格的第三人称限知叙事中，频繁换主语会被判定为 head-hopping（跳头），破坏视角一致性。取舍规则：目标风格是类型文学白描流 → 允许；目标风格是正统限知叙事 → 锁定单一感知主体，主语轮换仅限动作层（见 scale.md g3 动词链），不做感知层切换。

**执行检查**：写一段性场景，自问"这段读者现在站在谁的身体里？"如果一段话里始终只有一个人（无论她/他/我），就是视角锁死。视角锁死 = 读者的体验是单声道的；主语轮换 = 立体声。

## 内视角执行规则（硬性要求，防止写成"摄像头"）

**最大的内视角杀手：报告动词转述。** 模型默认用"她感觉到/她看见/她听见/她意识到"转述感官，这等于在读者和角色之间站了一个解说员——镜头贴在墙角，看"她"做这做那，读者始终进不去。

硬性规则：
1. **禁"她感觉到X"句式**："她感觉到自己被撑开"→ 直接写"胀痛从腿间涨到小腹"。感官直接呈现，不经过"她感觉到"这个中转站。
2. **禁"她看见自己"式外部观察**：除非有镜子/影像/第三人在场等合理媒介，否则内视角里不可能"看见自己"。"她看见镜子里的自己眉头皱起来"只在镜子场景成立。
3. **自由间接引语**：人物的想法直接进入叙述，不加"她想""她心想"。"她告诉自己：不能去"→ 直接"不能去。可她又想起下午在SPA里，她主动拉着小杨的手的样子"。判断、质问、矛盾都以心声形式直接出现。
4. **身体感知走"内感受"不走"外观察"**：写"胀/酸/烫/麻/紧"这类从身体内部涌上来的感觉，不写"她的身体发抖"（外观察）而写"腿根一阵阵发软"（内感受）。
5. **检查**：成稿扫描全文，统计"她（他）感觉到/看见/听见/意识到"出现的次数。一段性场景中超过 2 次 = 视角失守，改写。

**参照**：素材《老周》的"她告诉自己：不能去。可她又想起下午在SPA会所里，她主动拉着小杨的手的样子"——这是内视角；《窗外》的"他看见她仰着头叫'李局'"是陈明的旁观视角，两种都对，但要分清楚你写的是谁的视角。

## 羞耻的心理机制

羞耻是情色文学最贵的心理货币。它来自三处：

1. **身份落差**：让最高身份的人做最低贱的事（女警官→性奴、掌门夫人→被义子玩弄）。落差越大，羞耻越强。
2. **公开风险**：可能被看见/被听见（"声音会……被别人……听到！"）。公开性是羞耻的放大器。
3. **自我背叛**：做了自己鄙视的事（"自己竟然会主动迎上"）——自我认知的崩塌比外部羞辱更狠。

写作要点：羞耻一定要**写出它的具体来源**（因为身份？因为被看？因为自我背叛？），而不是笼统写"她很羞耻"。

**阈值递增的核心原则：靠"遮得更狠"，不是"脱得更多"**。

羞耻的推进不是"暴露程度"的单调递增——如果这样写，读者很快麻木。真正的推进是**遮掩行为的升级**：从嘴硬（语言遮掩）→ 遮挡动作（身体遮掩）→ 找借口（合理化遮掩）→ 沉默（遮掩失败）→ 自我背叛暴露（遮掩彻底崩溃）。每升一阶，她的遮掩方式换一种写法，读者的羞耻共鸣反而更强。

羞耻三来源按成本排序轮换使用：公开风险（最便宜，先用来建基线）→ 身份落差（中段主力）→ 自我背叛（压轴——她发现自己盼着某个瞬间，这是遮不住的）。

## 权力感的心理（施动者视角）

施动者的心理不只是"爽"，高手会写三样：
- **支配的确认**：对方的服从/求饶是权力生效的证据（"不服？那我就打到你服"）
- **征服的仪式感**：把性事当成征服仪式（父亲教训女儿/驯服烈马/开苞的占有宣言）
- **暴虐与温存的交替**：一边羞辱一边温柔（"我怎么舍得伤害你呢"）——交替本身是更深层的控制。

## 麻木与毁灭（深层心理）

当沦陷弧线走到尽头，心理描写进入更深层：
- **麻木**：不再抵抗，也不再感到羞耻（"她已经麻木了"）——这是比沦陷更黑暗的结局，常用于凌辱文的长期受害者。
- **斯德哥尔摩式的依赖**：受害者对施暴者产生依赖——心理描写要写"依赖的自我欺骗"（"他也只是对我这样"）。
- **毁灭感**：尊严彻底消失后的空虚（"失去了一切，包括肉体的和精神"）——这类文本的悲怆感来自对毁灭的如实呈现。

## 愧疚与快感的拉锯（人妻/绿文专用）

都市人妻偷情流派（见 genres.md 流派六）的心理核心不是"身体诚实 vs 意志抵抗"，而是**"对配偶的愧疚 vs 对快感的渴望"**——背叛对象不是陌生人而是枕边人，所以每次快感都附带一份亏欠，每次亏欠又反过来被快感压下去。

关键笔法：
- **愧疚的具体化**：愧疚要挂在具体物件/人物上（丈夫买回的西红柿、丈夫的补课时间表、结婚照），而不是抽象的"对不起"。
- **双重账本**：人物把身心分开记账（"自己的身体已经对不起王申了，生活一定要对得起王申"）——这种自我欺骗式的补偿逻辑，是沉沦持续下去的燃料。
- **时间表即提款机**：丈夫的作息表（几点下班、几点补课结束）就是偷情的安全窗口，也是愧疚的倒计时器。"他四点半就回来了"——紧迫感把愧疚和快感焊在一起。
- **堕落自我怀疑**：人物偶尔跳出性事自我审视（"难道自己真是他们眼里的骚货吗"），这种清醒的瞬间是弧线中最疼的节点——写沉沦就要写这些清醒时刻，否则弧线是平的。

## 写作指导要点

- 每个性场景先定"观察者"——从谁的心里看？
- 沦陷弧线要走完整：反抗→试探→半推半就→沦陷→结算。砍掉结算 = 没有心理深度。
- 羞耻要写具体来源，不要笼统。
- 身体反应是"诚实层"，让它和"意志层"明确打架，读者要看的就是这场架。
