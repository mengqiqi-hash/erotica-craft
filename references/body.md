# L3 身体描写

身体描写不是"报部位清单"，而是**视线调度 + 比喻系统 + 服饰符号**三位一体。

## 视线调度（先看哪里）

身体描写本质是一次"目光的旅行"，顺序即欲望的地图。经典调度：

```
脸 → 颈/锁骨 → 胸 → 腰 → 臀 → 腿 → 足
（自上而下，从"身份的脸"到"欲望的足"）
```

- **脸是身份的锚点**：先写脸，因为脸承载身份与羞耻。之后每向下一个部位，就剥落一层社会性。
- **间接曝光优于直接全裸（仅限 B/C 档雅文）**：半遮半掩（衣领微开、露出的锁骨、裙摆下的腿）比全裸更有效。写"被遮住的部分"比写"露出的部分"更催情——因为读者的想象参与进来了。**注意：这条只适用于克制档（修仙雅文等 B/C 档）。S/A 档（快餐/人妻/凌辱/老派）必须写实直给，身体反应和体液直接写，"间接曝光"不是它们的默认技法。** 尺度对照见 `references/scale.md`。
- **环境光参与描写**：烛光、月光、路灯、雨湿的衣衫——光决定身体的可见度，也决定氛围。
  ```text
  「季婵溪覆盖到膝盖的黑裙忽然逆风而舞……衣衫便贴得更紧，将臀背的灵秀曲线勾勒得更加稚美」
  「此刻在灯火微明的房间里，那里映照着烛光，染上了艳丽的颜色，显得暧昧而娇艳」
  ```

## 比喻系统（身体 ↔ 世界）

比喻必须与世界观绑定，这是质感的关键：

| 流派 | 身体比喻来源 | 例 |
|---|---|---|
| 修仙雅文 | 山水、剑器、天象 | 「断崖般挺秀的肩膀」「如珍珠般串起的足趾」「饱满如岳的丰乳」「肌肤……似倒影月色」 |
| 都市快餐 | 食物、日用品 | 「像两块碗状的细嫩豆腐」「大阴唇像是一对鲜红的筊杯」「鲔鱼生鱼片」 |
| 港台老派 | 器物、兵器 | 「肉腾腾的乳房」「火棒」「铁甲桃花蛇」 |
| 凌辱调教 | 肉、容器、机械 | 「砧板上的美肉」「人形玩具」「阴道内壁」 |

比喻的功能不只是"形象"，而是**给身体赋予属性**：
- 山水剑器 → 身体是风景/是武器 → 神圣与战斗感
- 食物 → 身体是食物 → 被吃/被消费感
- 容器工具 → 身体是器物 → 物化与可支配感

同一具身体，用什么比喻，就定义了权力关系的性质。

## 服饰符号（身份的性化）

脱衣的层次 = 身份剥落的层次。服饰在情色文学里从来不是背景，是**身份的铠甲**。

- **制服/职业装**：警服、校服、空姐制服、教师装、护士装——职业身份被性化，"制服诱惑"的本质是"权威被亵渎"。
  ```text
  「她身上穿的是标准的办公室女秘书制服……无论从打扮还是气质来看，都是个高雅骄傲的白领丽人。不过现在，这光彩照人的美女却狼狈的像头母狗」
  ```
- **贴身层**：丝袜、连裤袜、丁字裤、内衣——贴身层是"最后一层社会性"，它的存在感（蕾丝边、颜色、材质）比裸露本身更挑逗。
- **脱衣顺序的叙事**：先脱外衣（身份）→ 再脱贴身层（隐私）→ 最后防线。每脱一层，羞耻与兴奋同步上升。什么时候脱、谁脱、脱给谁看，都是权力叙事。
- **保留一件**：高手常让角色保留一件（丝袜/高跟鞋/内裤）——"部分裸露"的张力 > 全裸。

## 身体反应作为"证词"

身体反应（乳尖立起、湿润、颤抖、痉挛、足趾蜷缩）在叙事中承担"身体诚实"的功能——它背叛人物的意志，成为欲望的证词。

- **与意志对照**：身体反应 + 心理抵抗并置（"她紧咬牙关，不让自己发出一丝呼痛的声音"），形成"身体诚实 vs 意志抵抗"的核心张力。
- **细节要准**：足趾蜷缩、脖颈仰起、手指插入对方头发、青筋凸现——这些细微反应比"她颤抖了"有画面得多。
- **生理知识要可靠**：阴道收缩、G点、乳头充血——写实的生理细节让虚构的场景获得真实感。反之，违背生理常识的描写会瞬间击穿读者的信任。

## 写作指导要点

- 描写身体时心里有一张"视线路线图"，不跳跃、不报清单。
- 每个比喻问一句：它把身体变成了什么（风景/食物/器物）？这符合我要的权力关系吗？
- 服饰不只是"脱掉的道具"，先写服饰承载的身份，再写身份如何被剥落。
- 身体反应是角色的"诚实层"，让它与"意志层"打架。
