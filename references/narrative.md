# 白洁式叙事装置库

白洁式写实叙事的核心装置。写作时按需取用，不强制配齐（连续使用同一装置组合会模板化，换着用）。

## 零、伪第三人称视角（白洁叙事的核心引擎）

白洁式叙事区别于文学小说的根本写法：**第三人称外壳 + 第一人称感知内核**。主语写"她/人名"，但感知完全贴着主角走——读者感到"我在场"，叙述却能随时切视角。

执行规则：

1. **口语感知动词直接上**："觉着""感觉到""心里一荡"直接写，不用书面腔的"她感觉到"。白洁原文的形态："白洁觉着自己好像做了一场梦……感觉着那一下一下的摩擦、抽送"。
2. **自由间接引语**：心声不加"她想"，直接写（"不能去。可她又想起下午……"）。
3. **防摄像头**：最大的杀手是报告动词转述（"她感觉到/她看见/她意识到"），等于镜头贴墙角看"她"做这做那，读者进不去。改法：直接写感知内容，去掉"她感觉到"的壳。
4. **感知倒装**："一下睁开了眼睛，映入眼帘的是……"——把主语变成被看的东西，读者的视线从她的眼睛出发。
5. **主语是视角锚点**：连续同主语开头是"摄像头"写法；换主语=换身体（"他扒下她的裙子，她仰躺在床上"，读者先在他手上，再跳进她的身体）。
6. **身体部位独立成句 = 共享视角**："一对乳房在胸前隆起"——施动者眼中的被看之物，也是承受者身上的被感知之物，一个主语两个人都在场。
7. **边界（head-hopping）**：频繁换感知主体是类型文学的既定技法；在正统限知叙事中会被判定为跳头。目标风格是白洁式写实 → 允许；目标风格是正统限知叙事 → 锁定单一感知主体。

## 一、白描（把事情讲清楚）

- **短句**：一个句子一个动作，主谓宾清楚。
- **动作序列一步步写**：解扣子→摸到湿→进入→停→水声→收缩→射→擦→穿衣。模型倾向跳过中间步骤，白描要求每一步都写。
- **日常锚点**：楼道坏灯、洗白的床单、晒过的味道、窗台矿泉水瓶。细节让场景落地，是"像人写的"最强证据。
- **器官直呼**：阴茎/龟头/阴道/阴唇/乳房，不躲闪。密度口径见 scale.md。
- **声音直接**："啊……啊……"上屏，不转述"她忍不住叫了起来"。
- **作者隐身**：读者记住事情本身，不是"这段写得真好"。

## 二、悬置惊险装置

性场景进行中插入"危险信号"，高潮与危险重叠：

- 电话响（丈夫来电）、敲门声、人物逼近（丈夫走到门口）、有人偷看
- 规则：危险信号在情欲中段进入，制造"必须停却停不下"的拉扯
- 经典：偷情中丈夫来电，女方在插入状态下接电话编谎
- 时间线并置：丈夫买菜/下班同步逼近，日常动作越具体，逼近的距离就是倒计时

## 三、堕落弧光

长线结构的骨架，阶段单向推进：

| 阶段 | 心理 | 行为 |
|---|---|---|
| 完全被动 | 恐惧混乱 | 昏迷/被胁迫中发生 |
| 半推半就 | 抗拒+兴奋 | 嘴上拒绝、身体配合 |
| 利益合理化 | 自我说服 | 主动赴约，用交易麻醉自己 |
| 欲望觉醒 | 期待主动 | 主动索求 |
| 沉沦 | 习惯化 | 熟练配合、游刃有余 |

每次跃迁要有标志事件；跃迁后可以用一个"状态概括句"（如"半推半就、欲罢不能的娇羞"）。

## 四、身体诚实，语言撒谎

心理状态的核心呈现法：身体反应是真话，台词是假话。

- 嘴上"不要"、身体"湿了/夹紧/挺起"
- 心理只写"心里一荡""心里直痒痒"这类短促心绪，不写长篇独白
- 每 200-300 字至少给女主一个内心判断/自我质问/矛盾（"她恨自己的身体可控制不住"），严禁整段只有外部动作

## 五、伪装与表演场景的节拍

人物处于伪装状态（装醉、装睡、假装抗拒）时，表演链逐节核对：

1. **状态建立**：铺垫幕明确"她不是真醉"，读者知道、剧中人不知道
2. **触发点**：破功瞬间要有生理依据（被侵入的疼），选在戏剧最合理的时刻（完全进入后）
3. **反应链**：惊醒→确认→挣扎→语言→被压制→哭泣，逐级递进，跳级即断裂
4. **表演接管**：从真实反应转为可控表演的切换点，要能从行为辨认（挣扎"刚好"推不开），不写穿
5. **身体背叛**：伪装者身体反应与表演状态的冲突至少实写一处
6. **收场**：表演何时结束、收在具体物象上

## 六、道具链

- **酒**：壮胆、下药载体、事后台阶、饭局氛围
- **照片/把柄**：拍→示→藏→扩散，把身体关系固化成物证
- **电话**：悬置装置 + 关系确认
- **痕迹**：床单褶皱、水渍、内裤散落，丈夫的扫视就是暴露风险

## 七、称呼与市井对话

- 称呼即关系温度计：客气期"白老师"→暧昧期"宝贝"→亲密期"老公"→羞辱期"骚货"
- 对话带市井口语（咋、啥、呗），身份感靠语言浓度分层

## 八、收束（余韵三要素）

收束至少埋一样：心理落差（高潮后清醒/羞耻/后悔）、关系变化（权力易手/秘密形成）、情节钩子（有人来了/发现了什么）。收在具体物象上（一枚扣子、一摊水渍、一件外套），不收在感悟上。
