# 用词规则

本文件只管**词汇和句式的执行**，不管结构、视角选择、情节（那些由模型自主）。每条规则都是"这个词/这个句式怎么写"。

## 一、器官直呼

写实档写阴茎/龟头/阴道/阴唇/乳房，不用"那根东西""那个地方""身体的深处"躲闪（用户要求含蓄时除外）。"那根东西"是意象化手法的产物，写实档用它就是作者在闪躲。

## 二、声音直接写

叫床声、水声、肉体拍打声直接上屏，不转述：

```
✗ 转述：她忍不住叫了起来，声音越来越大。
✓ 直接：她咬着嘴唇，可声音还是漏出来："啊……啊……嗯……"
```

声音形态随节奏变化：压抑时短促单音节，渐入时长音，失控时连发并混着断续的词。对话同理：性爱中的人物不能当木头人。

## 三、感知用词（伪第一视角的词汇执行）

白洁式叙事的核心在词汇层是这样落地的（视角选择本身由模型自主，一旦选了贴身感知视角，用词必须按此执行）：

1. **口语感知动词直接上**："觉着""心里一荡"直接写，不用书面腔的"她感觉到"。
2. **自由间接引语**：心声不加"她想"，直接写（"不能去。可她又想起下午……"）。
3. **防摄像头壳**：报告动词转述（"她感觉到/她看见/她意识到"）等于镜头贴墙角，读者进不去。改法：直接写感知内容，去掉壳。
4. **感知倒装**："一下睁开了眼睛，映入眼帘的是……"——把主语变成被看的东西，视线从她的眼睛出发。

## 四、通用词红旗（库存词判据）

"淫水""交合处""蜜液"等库存词本身无罪（流派样本中高频出现），问题是"有词无现场"——只给通用词不给具体物象，读者不产生画面。判据：库存词出现时检查它是否挂在现场细节上——有细节（"顺着大腿根淌下，在床单上洇出一片深色"）保留；只有词没现场就**补现场**（位置、轨迹、洇痕），不是换词。

## 五、AI 味词簇扫描

单条出现不算，看**簇**（多个模式同时出现才确诊）：

- **AI 高频词**：确实、绝对、某种说不清的、仿佛、宛如、交织、弥漫、悄然、涌动（每 500 字超过 3 个即扫描）
- **强调式虚词**："真的""简直""完全"（删掉后句子依然成立就删）
- **公式化过渡**："那一夜之后""从那以后"（用具体事件锚定时间）
- **概括式收尾**："她知道自己会再去找他"（收在具体物象上）
- **器官词循环**：同一场景内器官词轮换称呼不超过 3 个（AI 的重复惩罚机制）
- **否定式平行**："不是……而是……""不在于……而在于……"
- **套路句式**：三段式排比、格言式总结、破折号滥用

保留真人的具体细节、矛盾情绪、长短句交错——这些是"像人"的证据，不要为了反 AI 味把个性也删掉。

## 六、每句带新信息

句子要递进，不绕圈、不同义反复。**豁免**：重复作为修辞手法时（排比、回声、强调、节奏性反复）不受此限——判准是"重复有没有功能"：有功能保留，无功能删除。

## 七、动作词汇（密度配合）

密度达标靠动作实写（手的位置、角度、进入与抽送的具体描写、身体的反应细节），不靠名词堆砌。动词要准确：抽插、研磨、顶弄、碾过承担不同的节奏暗示。
