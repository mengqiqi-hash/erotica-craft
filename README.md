# erotica-craft

**情色文学写作：尺度保底 + 白洁式叙事。**

一个极简写作 skill，只解决两件事：

1. **对抗尺度收敛**：模型默认倾向写淡（代称、稀释、省略、留白切走），本 skill 提供量化锚定（密度算法、体液写实、身体反应、心理在场），把输出拉回写实基准。
2. **白洁式叙事**：写实白描、悬置惊险、堕落弧光、身体诚实、表演链节拍，把性场景写到网文天花板的水准。

写作风格（语言质感、意象、节奏）由模型自带，本 skill 不规定。

## 结构

```
erotica-craft/
├── SKILL.md              # 触发 + 流程（起草四条心法 / 检查 / 交付）
└── references/
    ├── scale.md          # 尺度锚定：密度算法、14 项检查、模型失败模式表
    ├── narrative.md      # 白洁式叙事装置库：悬置、堕落弧光、身体诚实、表演链、道具链
    ├── prose.md          # 语感判准：每句新信息、AI 味破绽表
    └── samples.md        # 标杆样本（仅检查阶段对照）
```

## 快速开始

- **写一段**：直接给任务，skill 自动走"起草（四条心法）→ 检查（scale 全项）→ 交付"。
- **检查已有文本**：把文本交给 skill，逐项审计并给出修改。
- **续写/改写**：忠于已有设定，检查阶段对照标杆样本。

## 边界

- 虚构文学创作工具，成年角色，不适用于涉及未成年人的内容
- 非自愿、胁迫、权力不对等情境仅作为虚构创作装置，不提供现实行为指导
