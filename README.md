# erotica-craft

**情色文学写作技法分析与指导系统。**

一个把"成人向类型文学"当作严肃技术传统来研究的写作 skill。它不教你"写什么"，它保证"怎么写"——从语感到尺度，从视角到节奏，从流派惯例到人物心理，把模型的写作下限拉高，把上限留给你。

> **核心信念**：色文不是"普通小说+脱衣服"，而是一套独立的技术系统。技术含量全在走钢丝的手感里——在"直接"与"暗示"之间，在"快感"与"叙事"之间，在"人物尊严"与"情欲"之间。

---

## 它能做什么

- **分析**：拆解任意情色文学文本的写作技法（用词、场景、身体、心理、类型惯例五层）
- **指导写作**：按目标流派给出可执行的写法（场景三幕、对话推进、羞耻阈值、节奏配比）
- **续写/创作**：保持已有作品的人物设定与风格，产出连贯章节
- **质量保证**：成稿前自动过 14 条检查，防写淡、防纸片人、防 AI 味、防视角失守

## 安装

将 `erotica-craft` 目录放入你的 Agent 技能目录，或直接安装 `.skill` 安装包。

支持 Claude Code / OpenCode / Codex 等支持 skill 机制的 Agent 环境。

## 快速开始

**分析一段文本：**

> 帮我分析这段文字的写作技法，重点看用词系统和心理刻画。

**指导写作：**

> 我要写一篇都市题材的成人小说，开篇是男主和女主打麻将赌脱衣服，怎么写出张力？

**续写作品：**

> 继续写这个故事，女主一周后主动给男主打电话。（附上前文）

默认交付**干净最终版**。需要看检查过程时说"测试"或"检查说明"，会附上违规点→修改、密度数据、样本对照。

## 核心架构

### 四阶段调用流程

```
阶段一 准备：流派分诊 → 定尺度档位 → 定视角（默认伪第一视角）
阶段二 起草：只带五条心法，自由写，不逐条对照规则
阶段三 检查：14 条规则全量 audit（P0 硬性 / P1 重要 / P2 打磨）
阶段四 修改：只改违规点 → 平衡检查 → 忠实性终检 → 交付
```

**关键原则：生成与检查分离。** 起草时规则越少越流畅，检查时规则越全越精准。规则是检查工具，不是生成时的枷锁。

### 五条起草心法

1. **每句带新信息**（句子递进，不绕圈、不同义反复）
2. **把事情讲清楚**（短句、动作序列、日常细节锚点）
3. **器官直呼 + 密度**（A 档直接写，密度参照 A 档基准每百字 2-4 次）
4. **声音直接写**（叫床声/水声/对话直接上屏，不转述）
5. **主语轮换**（动词链收长句，焦点转移时换主语）

### 14 条检查规则（scale.md）

| 层 | 条目 | 防什么 |
|---|---|---|
| 尺度物理层 1-6 | 身体反应/体液/器官密度/文学性回避/场景稀释/高潮 | 写淡、代称、抽象带过 |
| 文学人文层 7-11 | 心理在场/对话个性/弧线连贯/感官多样/节奏差异 | 纸片人、万人同声、套路化 |
| AI 味扫描 12 | 通用层（prose.md 17 破绽）+ 色文专属补充 | 组装味 |
| 白描执行 13 | 短句/动作序列/日常锚点/器官直呼/朴素心理/声音直接/主语轮换 | 文学化展示 |
| 平衡检查 14 | 修正任何一条不得牺牲其他条 | 顾此失彼 |

## 创作理念

**1. Skill 是基线保底，不是风格替代。**
它保证下限（不写淡、不纸片化、不 AI 味、不污染），上限永远是作者自己的要求。

**2. 个人风格锚。**
把 3-5 篇你的代表作喂给 skill，它归纳出"我的文字长什么样"（句长、口头禅、论证方式、禁用词），然后按这个锚来写和查。用着用着，skill 就长成了你自己的样子——而不是"文学短篇的平均值"。

**3. 语感以规则承载，不以文本承载。**
样本只用于检查阶段的对照，不参与起草生成——防止跨作品的角色/意象泄漏进正文（"她想起白洁"是事故，"张敏"也是）。

**4. 生成与检查分离。**
起草时脑子里只有五条心法，写完了再用 14 条规则逐项审。起草想太多=写不流畅，检查不彻底=质量失控。

## 边界与伦理

- 本 skill 只用于**成年角色之间**的成人内容分析，不适用于任何涉及未成年人的内容。分析前若文本出现未成年信号（萝莉/幼女/未成年等与性场景关联），立即停止并说明原因。
- 本 skill 输出的是技法分析与写作指导。默认交付最终版；示范与检查说明以"点出技法"为目的。
- 续写须忠于已有人物设定：不编造素材里没有的事实，不为爽而让角色做出设定外的事。
