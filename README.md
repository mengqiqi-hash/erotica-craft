# erotica-craft

**情色文学写作：尺度锚定 + 用词规则。不干涉创作。**

一个极简写作 skill，只做两件事：

1. **尺度锚定**：模型默认倾向写淡（代称、稀释、省略、留白切走），本 skill 提供量化锚定（密度算法、体液写实、身体反应、心理在场），把输出拉回写实基准。
2. **用词规则**：器官直呼、声音直接、感知用词（伪第一视角的词汇执行）、通用词红旗、防 AI 味词。

结构、视角、情节、叙事声音、节奏全部由模型自主创作，skill 不教怎么写故事。

## 结构

```
erotica-craft/
├── SKILL.md              # 触发 + 流程（起草 / 检查 / 交付）
└── references/
    ├── scale.md          # 尺度锚定：8 项检查 + 密度算法 + 失败模式表
    ├── lexicon.md        # 用词规则：器官直呼、声音直接、感知用词、通用词红旗、AI 味词
    └── samples.md        # 标杆样本（检查阶段对照密度与用词）
```

## 快速开始

- **写一段**：直接给任务，模型自由创作，成稿后对照 scale + lexicon 检查，只改违规点。
- **检查已有文本**：把文本交给 skill，逐项审计尺度与用词。
- **续写/改写**：忠于已有设定，检查阶段对照标杆样本。

## 边界

- 虚构文学创作工具，成年角色，不适用于涉及未成年人的内容
- 非自愿、胁迫、权力不对等情境仅作为虚构创作装置，不提供现实行为指导
